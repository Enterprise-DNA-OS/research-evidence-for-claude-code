# Record a second-person finding review

Read CLAUDE.md. Run `npm run research -- approve-finding --finding="<finding>" --reason="<review basis>" --actor="<reviewer>"`. Use `--json` when analysing the result. Substitute values from the operator or existing records. Do not invent them.

Read evidence first. A different actor name is required. If contradictions exist, describe them and add --acknowledge-contradictions only after the operator has reviewed them. Names are not authenticated signatures.

Never send, publish, or contact participants. This workspace is for a trusted research operator.
