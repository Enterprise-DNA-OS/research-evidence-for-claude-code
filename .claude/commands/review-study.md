# Record a completed study review

Read CLAUDE.md. Read the study and its attention queue first. Run `npm run research -- review-study --study="<study>" --review-due=<YYYY-MM-DD> --reason="<review outcome>" --actor="<operator>"` only to record a review the operator has completed. The next date must be today or later. This clears the study's overdue review, not its unresolved source or decision issues. Report the new date and outstanding work. Nothing is sent.
