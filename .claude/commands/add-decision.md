# Assign follow-through on a reviewed finding

Read CLAUDE.md. Run `npm run research -- add-decision --finding="<finding>" --title="<action>" --owner="<owner>" --due-on=<YYYY-MM-DD> --actor="<operator>"`. Use `--json` when analysing the result. Substitute values from the operator or existing records. Do not invent them.

Show the records used and identify missing evidence. On ambiguity, present every candidate and obtain the intended record.

Never send, publish, or contact participants. This workspace is for a trusted research operator.
