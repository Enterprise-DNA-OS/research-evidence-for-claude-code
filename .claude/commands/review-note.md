# Record an actual source-use review

Read CLAUDE.md. Run `npm run research -- review-note --note="<note>" --permission=<pending|allowed|withdrawn> --reference="<review evidence>" --reviewed-on=<YYYY-MM-DD> --retention-due=<YYYY-MM-DD> --actor="<operator>"`. Use `--json` when analysing the result. Substitute values from the operator or existing records. Do not invent them.

Read the source with show --type=note --record="<note>" --review-source only for this internal review. Use the documented purpose and actual permission evidence. A date is an internal review control, not a legal retention period. Review changes return dependent findings to draft.

Never send, publish, or contact participants. This workspace is for a trusted research operator.
