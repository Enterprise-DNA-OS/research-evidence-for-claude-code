# Add a read-only view

Read CLAUDE.md and views.json. Establish the question and audience. Use current SQL views and columns to add a SELECT-only section to views.json. Prefer approved_findings for briefs and note_checks for operational metadata. Never expose held source text or quotes through a general dashboard. Run npm run view, inspect the HTML and verify its answer against the CLI. The renderer runs a read-only transaction. Do not add a web app, writable form or server.
