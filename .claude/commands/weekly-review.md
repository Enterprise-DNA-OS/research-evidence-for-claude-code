# Prepare the Monday research review

Read CLAUDE.md. Run `npm run research -- weekly-review`. Use `--json` when analysing the result. Substitute values from the operator or existing records. Do not invent them.

This combines attention, coverage and decisions. Explain overdue work first, then weak or contradictory evidence, then each owner and next date. Do not turn a small sample into a population claim.

Never send, publish, or contact participants. This workspace is for a trusted research operator.
