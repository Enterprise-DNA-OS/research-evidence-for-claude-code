# A research record you can ask questions of

The database holds the study, source text, quotation, finding and follow-through. The coding agent runs the same CLI an operator can inspect. Read-only HTML shows the weekly review and the paperwork without running a web service.

A specialist research screen gives you collaborative tagging, clip playback, visual synthesis boards and mobile capture. This base does not provide those experiences, automatic transcription or live channel ingestion. It is useful on its own for text research evidence and accountable decisions. Enterprise DNA builds agreed screens and connections into a custom version.

You own the database and the MIT code. Hosting, coding-agent access and administration still need an owner. Start with a small export, check the evidence and the review rules, and extend what your team actually needs.
